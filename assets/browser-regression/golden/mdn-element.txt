		<p></p>
			<code> Element </code>
			is the most general base class from which all element objects (i.e., objects that represent elements) in a
			[1624]<a> Document </a>
				[1625]<code> Document </code>
			inherit. It only has methods and properties common to all kinds of elements. More specific classes inherit from
			<code> Element </code>
			.
		<p></p>
			For example, the
			[1630]<a> HTMLElement </a>
				[1631]<code> HTMLElement </code>
			interface is the base interface for HTML elements. Similarly, the
			[1632]<a> SVGElement </a>
				[1633]<code> SVGElement </code>
			interface is the basis for all SVG elements, and the
			[1634]<a> MathMLElement </a>
				[1635]<code> MathMLElement </code>
			interface is the base interface for MathML elements. Most functionality is specified further down the class hierarchy.
		Languages outside the realm of the Web platform, like XUL through the
		<code> XULElement </code>
		interface, also implement
		<code> Element </code>
		.
