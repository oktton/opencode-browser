Cross-origin frame, scrolled inside

The frame below runs out of process, so commands for it go through its own CDP session and hit testing there uses that document's coordinates. Scrolling it internally is the only way to tell those apart from viewport coordinates — an unscrolled frame makes both look correct. The harness scrolls it through the child session, since a parent cannot script a cross-origin child.
